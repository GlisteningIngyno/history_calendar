## Календарь с историческими событиями
Приложение на Qt/QML для просмотра исторических событий и дат в календаре.

## Возможности
* Добавление и удаление даты с событиями
* Экспорт и импорт(.csv) файлов со всеми датами
* Полная очистка базы данных в приложении
* Поиск события по нужной дате
